# Screenshots for Shopify App Store

This directory will contain 3-5 screenshots for the Shopify App Store submission.

## Required Screenshots

Place the following files in this directory:

1. `01-customer-offer-mobile.png` - Mobile offer page (375×667px) - **PRIORITY**
2. `02-merchant-dashboard.png` - Dashboard with metrics (1920×1080px)
3. `03-settings-page.png` - Settings configuration (1920×1080px)
4. `04-offer-email.png` - Email example (optional)
5. `05-confirmation-screen.png` - Success confirmation (optional, mobile 375×667px)

## Capture Instructions

See `../../../SCREENSHOT_GUIDE.md` for detailed capture instructions.

## Upload to Shopify

Once screenshots are captured and placed here:
1. Log into Shopify Partner Dashboard
2. Navigate to Apps → Pleero → App Store Listing
3. Upload screenshots in order (drag & drop)
4. Add captions as specified in SCREENSHOT_GUIDE.md
